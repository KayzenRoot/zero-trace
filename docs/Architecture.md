# Architecture proposal
Unity/C# Windows-first; local Editor baseline 6000.3.29f1 Windows x64 Mono approved in PF-01; IM-01 actual package lock (URP 17.3.0, Localization 1.5.14, Test Framework builtin 1.6.0); UI Toolkit built-in, pure domain assembly no UnityEngine references. C# headless deterministic simulation separated from Unity presentation through typed commands/events and projections. Layers: presentation; application; domain simulation; persistence adapters; online authority; Steam adapter. Offline saves isolated from online inventory, authority and score. SQLite local and PostgreSQL online candidates; migration, atomic ledger, idempotency and recovery ADRs required. Restricted interpreter with capability allowlist, bounded execution, no host bridges; no actual exploits or arbitrary OS/network commands. Steam identity verified server-side, adapter test doubles before credentials. No committed proprietary SDK binaries. No dependency cycle: use D00–D19 order; split M17/M21/M22/M30 by slice. Asset metadata tracked; ignore generated Unity artifacts. Architecture choices pending preflight ADRs.
D01 cloud Unity CI qualification is mandatory in QA-01 under ADR-009; not qualified in PF-01. Local tests must use a verified licensed official interface. No change to simulation boundaries.
ADR-010 qualifies CLI/Pipeline 1.0.1 for local development only; single licensed interactive Editor, authenticated loopback, Runtime off; keep tooling separate from runtime, remove before distribution and verify artifact.
