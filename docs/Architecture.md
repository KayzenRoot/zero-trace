# Architecture proposal
Unity/C# Windows-first; pin supported Unity LTS/editor and package versions in D01 preflight; URP, UI Toolkit proposed. C# headless deterministic simulation separated from Unity presentation through typed commands/events and projections. Layers: presentation; application; domain simulation; persistence adapters; online authority; Steam adapter. Offline saves isolated from online inventory, authority and score. SQLite local and PostgreSQL online candidates; migration, atomic ledger, idempotency and recovery ADRs required. Restricted interpreter with capability allowlist, bounded execution, no host bridges; no actual exploits or arbitrary OS/network commands. Steam identity verified server-side, adapter test doubles before credentials. No committed proprietary SDK binaries. No dependency cycle: use D00–D19 order; split M17/M21/M22/M30 by slice. Asset metadata tracked; ignore generated Unity artifacts. Architecture choices pending preflight ADRs.
