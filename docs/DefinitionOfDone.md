# Definition of Done
Per WO: locked base+source hashes; scope met; code reviewed; required tests and build passed; regression/security evidence; no HIGH/CRITICAL; docs and proposed checkpoint delta; independent objective audit; approved PR merged via squash after checks. Per release: versioned reproducible artifact deployed only to authorized environment and validated, playable scope and content counts, locale/accessibility QA, licenses and AI provenance, recovery and rollback, support, approved Steam gates where relevant. D00 documentation-only: originals verified, visual corrections/ratification, complete backlog, architecture decisions identified, CI docs check, no implementation. Do not treat a planning PR as product completion.
