# Context Lock protocol
Each executable WO must record base main SHA, branch/head, approved predecessor issue/PR, GDD/catalog SHA-256, checkpoint/decisions/scope/DoD/architecture hashes, applicable visual spec and exact relevant file paths. Recompute after fetch before edits and before final review. Any material change => STALE; stop and recompile scope against new base. Do not lock against draft or unapproved sources. Evidence records commands/results, dependency and security gates, base/head and proposed checkpoint delta. Cache stable AGENTS and shared docs, use git diff and targeted source ranges; never send full catalog for a task that needs only a mission ID.
