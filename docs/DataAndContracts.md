# Data and integration contracts
Proposed entity IDs stable: player, virtual host, mission, event, evidence, script, inventory item, account, transaction, escrow, guild, season. Explicit schema versions; offline and online namespaces disjoint. Integer ZC, ledger append-only, atomic state transitions and idempotency; define invariants before code. Typed command/result/event envelope with schema version, correlation ID, actor, authorization, error category and retry semantics. Never expose sensitive data. UI states Loading Empty Ready Error Offline Read-only Pending Conflict; pending not success. Version migration, backup and restore evidence. Full schemas/API ADRs before relevant increments.
