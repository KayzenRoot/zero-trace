## Objective

Deliver a small, genuinely interactive local/offline technical playable prototype in the existing Unity project. It must be explicitly identified as a prototype and must not be represented as canonical released content, D02 simulation completion, or D01 completion.

## Scope

1. Preserve existing Unity project, package versions/lock, pure `ZeroTrace.Domain`, startup screen, localization foundation and existing tests.
2. Add an optional localized launch path from the startup screen into a small first-person room.
3. Implement keyboard/mouse movement and a ray-based E interaction with a fictitious computer. Represent OFF, BOOTING, READY and SHUTDOWN explicitly.
4. Implement a minimal UI Toolkit NULL OS-style desktop with a status/navigation area, simulated clock, app launch buttons, one active app window, close/power actions and visible feedback.
5. Implement small fictional Mail, File Manager and Academy surfaces. Files and messages are synthetic in-memory data, never the host filesystem.
6. Implement one bounded tutorial: inspect fictional file names, select the file named by the briefing, receive distinct failure/success text, retry, and restart.
7. Save/load only prototype completion and attempt count using the app-owned local persistent-data path; no account/personal data.
8. Keep all game/model logic deterministic and free of UnityEngine references where practical; isolate the Unity presentation and persistence adapter.
9. Add targeted EditMode and PlayMode regression tests, use only the existing Editor/packages, and inspect the actual local playable view where the Editor permits.
10. Publish Evidence Bundle and unpromoted Checkpoint Delta; commit/push this branch and create only this independent PR.
