## OBJECTIVE

Prepare an optional, local/offline visual refinement that makes the existing V01 technical prototype room read clearly as a modest single-room starter apartment, aligned with Visual Master v0.2.0. Preserve the recovery computer, exactly one monitor, and the existing playable loop. Achieve a polished visual result using only original Unity primitives and the already installed project capabilities.

This is a visual refinement of the already merged technical prototype. It is not a canonical mission, D01 completion, D02 simulation, D09 vertical slice, release feature or production asset approval.

## SCOPE

After the execution gate is satisfied, the executor may:

1. Refine the generated room in LocalPrototypeRoomFactory only, keeping all generated objects under the existing prototype root.
2. Compose a compact studio-apartment visual with:
   - a simple entrance/door frame;
   - a window with a static, non-interactive exterior treatment;
   - one modest living/sleeping cue, such as a compact bed or sofa silhouette;
   - modest storage/shelf details;
   - the existing small desk and recovery computer.
3. Keep exactly one visible physical monitor. The computer remains the only interactive world object and preserves the existing interaction collider/contract.
4. Use the Visual Master tokens: Obsidian, Carbon and Frost as the base; restrained Lime/Cyan accents; Magenta only as a limited accent. Avoid neon overload, flashing and motion required to understand state.
5. Use only the already available URP/Lit or existing fallback shader and materials created by the prototype. No imported textures, meshes, fonts, models, audio or third-party assets.
6. Keep the existing room footprint or reduce it if needed for a compact composition; never enlarge the current play area. Any footprint/bounds change must preserve safe spawn, collision and recovery behavior.
7. Add focused PlayMode regression tests for apartment composition, single-monitor/single-computer invariants, interaction ray, room boundaries and camera/root restoration.
8. Capture actual PlayMode evidence from the existing licensed Editor at supported viewports, without creating a Player build.
9. Publish a new Evidence Bundle and a proposed Checkpoint Delta that explicitly leaves the canonical Checkpoint unchanged and unpromoted.
