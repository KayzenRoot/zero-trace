## Findings
F01 MEDIUM, AC03/05: StartupController.OnEnable subscribes to global SelectedLocaleChanged before Start binds controls/loads assets. HandleLocaleChanged sets ready=true and calls RenderLocale without checking viewBound/required assets/initialization state. An early valid-locale event can dereference null UI, or render fallback readiness before data is loaded. ShowUnavailable sets ready=false and disables buttons but leaves subscription active, so a later locale event can set ready=true/render a ready status after failed initialization without re-enabling buttons. Current test toggles controller only after successful init; missing-key unit test is a static fallback call, not actual failed initialization lifecycle. Correct the initialization state/guard and event subscription ordering, ensure deterministic EN initial render even if same locale already selected/no change event, safe disable/re-enable during initialization, failed state stays truthful unless explicit successful recovery. Keep solution small; do not redesign Localization system. Handle absent view safely with observable bounded failure, no null access/hang. Fallback messages for normal PT display should use PT fallback when available; distinguish genuine unavailable state from ready. Emergency default EN on unavailable data is acceptable if documented and not falsely ready. Test actual lifecycle, early/repeated locale, failure and no duplicate event handling; test must observe controller behavior rather than merely counting events of a separate global subscriber. No production test-only switches or arbitrary new API.
F02 MEDIUM, AC04/05: StartupController.RenderLocale sets locale-button--selected only; Startup.uss selected styling communicates active language by green border/background. No textual/shape/semantic selection marker separate from color; focus and selected borders share color. AC04 requires no color-only status. Add a small persistent localized text/icon+text marker or unambiguous textual current-language indicator, keep keyboard focus visibly distinct, expose meaningful labels as supported. Preserve minimal scene and layout. Test actual selected marker/focus in both languages and before/after switch. Recheck all keys in both tables, whitespace/nonblank, layout and expanded text at 1080p/150% equivalent; existing screen captures show normal slice only as executor evidence, refresh after changes.
F03 LOW, AC05/07 proof quality: PlayMode event observer localeChangeCount measures global events, not number of controller render/subscription invocations; synthetic key/pointer events test UI dispatch, not physical input end-to-end. Preserve existing useful tests, add targeted behavioral regressions for F01/F02 and one official Editor UI smoke with real keyboard/mouse (owner-operated if needed), or clearly distinguish synthetic evidence from actual smoke and satisfy AC04 with owner observation. Ensure cleanup of test-added global subscriber and panel scale on failure, and avoid misleading test denominator (Addressables example separate).
