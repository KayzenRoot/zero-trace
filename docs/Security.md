P3 ledger/inventory/escrow conservation, concurrency, retries, durable ACK and restore. P4 trusted server score, replay/rubric/version validation. Independent review for high assurance; separate audit pass not executor self-attestation. No production secrets or Steam keys in public repo. Report vulnerabilities privately through owner-approved channel; never include exploit details in public issues.
